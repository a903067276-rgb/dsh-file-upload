# 重启后验证清单（dsh-file-upload）

> 重启由 `scripts/restart-dsh-web.sh` 自动完成。重启后本会话自动恢复，
> agent 按此清单逐项验证；每项完成标注 ✅/❌。

## 前置确认

- [ ] 浏览器打开 http://127.0.0.1:3080，回到本会话（dsh-file-upload 工作区）
- [ ] 输入框工具行出现「📎 上传」按钮，与默认「+」命令按钮视觉区分明显
- [ ] 按钮 title 提示"上传文件到当前项目（也可直接把文件拖进窗口）"

## 功能验证

- [ ] 点「📎 上传」→ 弹出系统文件选择器（可多选）
- [ ] 选 1 张图片 → 项目 `uploads/` 出现 `时间戳-原名` 文件（内容与原图一致）
- [ ] 输入框自动出现 `[上传文件] /…/uploads/xxx.png`（已有草稿文字被保留在路径前）
- [ ] 发送该消息 → 模型自动调 `view_image` 识别图片（本机 dsh-vision）→ 识别结果正确
- [ ] 直接把图片拖进窗口（页面任意位置）→ 同样保存 + 路径进输入框，**不再出现"当前模型不支持图片"**
- [ ] 拖入非图片文件（如 .md / .zip）→ 也能保存 + 路径进输入框
- [ ] 多文件同时上传 → 路径逐行插入输入框
- [ ] 超大文件（>25MB）→ 按钮短暂提示"超过 25MB，已跳过"，不崩溃

## 边界

- [ ] 文件名含中文/空格/单引号 → 正常保存、路径可读
- [ ] 切换会话 → 按钮跟随当前会话，文件落在对应项目 uploads/
- [ ] 上传中按钮变灰（"上传中…"），完成后恢复
